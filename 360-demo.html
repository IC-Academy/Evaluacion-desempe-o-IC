Evaluación 360° · Calidad de servicio y liderazgo

Evaluaciones asignadas por dependencia, no por preferencia

Cada participante recibe un mínimo de tres áreas o funciones con las que existe una relación de servicio. Dos se asignan por dependencia operativa y una se incorpora de forma aleatoria dentro de un universo elegible. El evaluador no puede sustituir ni elegir a quién calificar.

🎲
Regla de neutralidad propuesta

La asignación aleatoria ocurre antes de iniciar la encuesta. Solo se eligen áreas con interacción razonable para evitar respuestas sin contexto.

Cómo funcionaría la asignación

Modelo propuesto para preservar neutralidad y pertinencia
1
Perfil y contexto

El sistema identifica área, puesto, nivel y relaciones de servicio del participante.

2
Matriz de dependencias

Se crea un universo de áreas que realmente prestan servicio o interactúan con ese rol.

3
Asignación balanceada

Se asignan al menos dos funciones relevantes y una adicional de manera aleatoria entre las elegibles.

4
Bloqueo

Las asignaciones quedan fijas durante la campaña. No existe botón para cambiar evaluado.
